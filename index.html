webhook-relay

In progress · v0.3

A webhook delivery service in Java 21 and Spring Boot. PostgreSQL is both the event store and the work queue. Delivery is at-least-once, with retries, dead-letter replay and signed requests.

  • 2,564 / 2,564 deliveries succeeded across local k6 load tests
  • −96.7% p95 end-to-end latency going from 1 worker to 2, with no code changes
  • Crash recovery verified: a SIGKILLed worker's delivery was picked up by another worker after its lease expired

Controlled local experiments with a mock receiver, not production guarantees.
